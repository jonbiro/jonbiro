<h1 align="center">Hi, I'm Jonathan (Yoni) Biro 👋</h1>
<p align="center"><strong>QA Automation Engineer / SDET · Software Builder · Founder of <a href="https://biro.dev">Biro.dev</a></strong><br>Los Angeles, California</p>

I build technology that reduces friction instead of adding to it. My background is in **software quality, test automation, and engineering reliability**. These days, I'm also building **Biro.dev**: practical, accessibility-minded software for neurodivergent people, people with disabilities, and families.

### What I'm building

| Project | The idea | Current stage |
| --- | --- | --- |
| **[AddvancedFocus](https://biro.dev/addvancedfocus/)** | Executive-function support for starting tasks, planning realistically, and finding your way back after interruptions. [Try the interactive demo](https://biro.dev/addvancedfocus/#concept-demo). | In development; the website demo uses scripted examples, not live AI. |
| **[OpenCall](https://biro.dev/opencall/)** | Helping people pause, understand warning signs, and make safer decisions about suspicious calls and messages. | Native iOS prototype in development; not publicly released. |
| **[CareBridge](https://biro.dev/carebridge/)** | Making care coordination, responsibilities, and follow-ups easier for families to manage. | Early product concept. |

### How I approach software

- **Reduce cognitive load.** Help people identify one useful next step rather than demanding more planning.
- **Build for different people.** Make interfaces clear, flexible, and accessible by design.
- **Earn trust.** Prioritize reliable behavior, privacy, user control, and honest descriptions of what works today.
- **Test what matters.** Bring a quality-engineering mindset to mobile apps, the web, automation, and CI.

I'm especially interested in the intersection of **assistive technology, AI-assisted workflows, native apps, and thoughtful user experience**. Much of my hands-on work spans Python, JavaScript, Swift/iOS, automated browser testing, and GitHub Actions.
